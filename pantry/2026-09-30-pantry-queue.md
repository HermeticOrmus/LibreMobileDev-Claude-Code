# Pantry queue: LibreMobileDev-Claude-Code

## How this fills

1. Read the latest competitor map, X mine and people mine.
2. Propose 5 to 8 Goal atoms that answer their themes. The Menu needs at least 3.
3. Each atom needs a Done predicate someone else can check on this repo, a surface, the evidence rows it answers, and a confidence (high, medium or low).
4. Save as `YYYY-MM-DD-pantry-queue.md`; the Menu reads the newest one.
5. Retire an atom only with a bullet under "Explicitly not stocked" of the form `<Title>: shipped, PR #N` or `<Title>: parked, <reason>`.

## Explicitly not stocked (and why)

- An MCP server of our own for device control. Not stocked: mobile-mcp, MobileBuildMCP, agent-device and the Claude Code Desktop simulator pane already do it (Map), so the `device-loop` atom points at them instead of competing.
- Depth passes for all 19 shell-improved plugins at once. Not stocked as one atom: too large to check. The swift-ios and kotlin-android atoms are the first slices, chosen because X evidence names them.
- Anything that needs paid EAS, a paid device farm or a store developer account to verify. Every Done predicate above runs on a free local toolchain.
