## Product

- Name: LibreMobileDev-Claude-Code, the `libre-mobiledev` Claude Code plugin marketplace, v1.0.0. 0 stars (gh api, 2026-09-30).
- Flagship: `flutter-development`, the one plugin the README marks depth-complete. The other 19 domain plugins are marked shell-improved.
- Our surfaces: 21 plugins in `.claude-plugin/marketplace.json`. 20 domain plugins each ship one agent, one slash command and one skill (Flutter, React Native, iOS, Android, cross-platform, performance, testing, architecture, accessibility, offline-first, push, deep links, camera, location, gestures, payments, CI/CD, ASO, analytics, security). `libre-mobiledev-hooks` adds PreToolUse, PostToolUse and SessionStart hooks. Install with `/plugin marketplace add HermeticOrmus/LibreMobileDev-Claude-Code` or `./setup.sh`. CI validates the marketplace and every plugin and installs all of them into a clean config. No MCP servers, no device or simulator control, no evals.

## What the map says

- Our clearest lead: signing-key and destructive-command hooks, and breadth across the feature layers (push, deep links, offline sync, payments, location) that no single competitor covers in one marketplace.
- Our clearest gaps: no build, run or screenshot loop (every official vendor and three MCP servers have one), no evals (Expo and VGV ship them), no store privacy coverage, and MASVS is not referenced even though mobile-security exists.
- Official vendor packs (Flutter, Android) do not accept outside pull requests; this repo does.
